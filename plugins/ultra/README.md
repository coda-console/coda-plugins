# Ultra

输入框的 Ultra 模式（Coda 的[输入框模式](https://github.com/coda-console/coda/blob/main/docs/plugins.md#输入框模式)）：开着时，主 Agent 主动把能并行的活拆出去，
按名单用 `spawn` 派给 Coda 子会话，自己做卡住的那一步，结果自动回来后汇总、验证。提示词与时机参照 Codex 的 `ultra` 推理档（主动多 Agent 委派）和 Claude Code 的 Ultracode。

从 Coda 的商店安装（npm 包 `@coda-console/ultra`，分类「工作流程」），不随 Coda 默认装上。Coda 不认识 Ultra：模式、参数、给 Agent 的话都在这个插件里。

**用法**：输入框打 `/ultra`（或在 `/` 菜单、iPhone 的「+」里选），输入框进入 Ultra，模式条上写着所选的模板和名单里 Agent 的图标；点模式条打开参数：

| 参数 | 是什么 |
| --- | --- |
| 模板 | 设置 `ultra.templates` 里的模板，加「自定义」；选一个就把名单换成它的，手动改了名单就变成「自定义」。进入时取排第一的模板 |
| 子 Agent | 名单，一行一个：Agent 组合（Agent、模型、推理强度、配置项）和「什么时候派给它」。名单里没提到的活，Agent 用自己的 Agent 和模型派 |

模式开着时发的每条消息照常发给这个会话，工具栏上的 Agent 和模型不变；点 × 退出。

**告诉 Agent 什么**（`ultra.mjs`，经 Coda 的「顺带告诉」随下一轮带上）：

- 开着后发的第一条，以及名单改过之后的第一条：打开主动委派，原先「没要求就别派」不再适用，用户在消息里说的优先；怎么拆（先定计划、卡住的那步自己做、子任务具体自包含、写入范围不重叠、派出去后做自己的、不重做）；名单，一行一个，写成 `spawn` 要的 `agent`、`model`、`effort`、`mode`、`options`。
- 之后每 10 条提醒一句「仍在开着」。
- 名单写得太长、连同说明超过 Coda 一次能告诉 Agent 的长度（4000 字）时，那条消息发不出去，界面说明原因；改短后再发就照常告诉。
- 退出时说一句关掉了、回到「有要求才派」；一条都没发过就不说。

同时在跑的子会话有多少由 Coda 管（「会话生命周期」插件的设置「同时执行的子会话」），满了 `spawn` 当场失败，提示词告诉 Agent 这时自己做或等一个做完。

**设置** `ultra.templates`：一列行，每行「模板名、Agent、什么时候派给它」，同一个模板名的几行是一个模板。默认带两个模板「均衡」（Claude Opus 做界面、文案、品味和整洁性的活，Codex 做简单活、调研和验证）和「只用 Codex」，可以改、加、删。

测试在 `test/plugins/ultra/`。
