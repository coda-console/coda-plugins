# Codex 多账号

在 Coda 内管理 Codex 账号：自动纳入已有登录，添加与移除账号、自动续期、查看额度和使用完全重置；接管资源页的「Codex」（与 Codex 自己的登录同一个类型，同一账号合成一行），所选账号在会话开始和两轮之间生效。

依赖 `codex`，接上它的「账号来源」（协议见 `plugins/codex/README.md`）。只装 `codex` 不需要它；不默认装上，需要时在「设置 › 插件」里安装。账号的导入、添加与存放见仓库根 README 的「Codex 账号与额度」。

- **资源**：资源类型也叫「Codex」（同 `codex` 自己的，接上后那边输出为空），每个账号一个资源，名字是别名（邮箱），
  额度与完全重置的读数同 `codex`；会话正在用的那个多一个读数「状态 · 正在使用」。某个账号的登录没有了、过期或无效时，只写在它自己那一行；别的读不到（网络、超时、服务端出错、Codex 没有给出某个账号的任何额度、账号列表读不了）命令以非零退出，原因写在标准错误的最后一行，Coda 保留上一份记录，资源页显示「更新失败：原因」。
  所选的账号不在插件里时另有一行「所选账号」写明。至多 40 个账号、合计不超过 60 KiB。旧登录导入失败时记录照写：一行「Codex 账号」写原因，登录入口照常在。记录命令是 `scripts/resource.mjs`，不定时（没有 `every`），资源页打开、点「刷新」和每个操作之后运行。
- **按钮**（在「···」里；都是操作 `act`，由 `scripts/act.mjs` 按 `{ action, args }` 分派 `select`、`reset`、`remove`）：「切换使用」（先用这个账号核对一次，通过才记下；会话在下一个边界换过去）、
  「使用完全重置」（同 `codex`，用这个账号的令牌）、「移除账号」（删掉插件保存的登录；移除的是正在用的，要再选或添加一个）。
- **身份**：知道邮箱的账号带与 `codex` 同一写法的身份（邮箱与工作区），同一账号在几台上、或与本机登录是同一个时，Coda 的资源页只显示一行。
- **登录**：操作 `sign-in`（`scripts/sign-in.mjs`）运行 `scripts/login.mjs`（Codex 的设备码登录，每次在私有目录里，登完核对才保存），设备码的解析、用 `coda progress` 上报、20 秒首链超时与收尾用 `scripts/device-login.mjs`：与 `codex` 的同名文件一字不差，随本插件带着，旁边装的 `codex` 是没有这个文件的旧版时登录照样能起（测试核两份一致，改一份另一份跟着改）。`codex` 自己的登录入口接上它之后也走 `login.mjs`。
